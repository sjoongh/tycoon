## Covered behavior

- 3·6·9…구역은 일반 완료 대신 8초 체크포인트 보스를 명시적으로 시작한다.
- 목표는 비버프 초당 생산 8초분과 기본 탭 12회분으로 스냅샷되고, 실제 생산·탭·피버는 진행에 기여한다.
- 성공은 구역 완료 표 보상 +35%, 실패·건너뛰기는 페널티 없는 기본 보상으로 처리한다.
- 보스 결과 카드가 사라진 뒤에만 구역을 전진하고 작전 회의를 연다.
- 진행 중 저장이 만료돼도 재접속 시 실패 완료로 정리되어 구역이 잠기지 않는다.
- 모바일 보스 카드가 세계 탭을 막지 않고, 중앙 알림·피버 결산·작전 모달과 겹치지 않는다.
- 작전 카드는 먼저 선택한 뒤 하단 확인 버튼으로 채택한다. 보스 직후 연타가 런 빌드를 몰래 바꾸지 않는다.
- 390×844, 360×740, 1280×900에서 overflow가 없고 44px 건너뛰기/확인 타깃과 reduced-motion을 유지한다.

## Hands-on alpha result

- 고강도 60초: 487탭, 11구역 도달, 보스 3회 성공, 작전 선택/실제 보유 3/3, 오류 0.
- 캐주얼 70초(420ms 탭 간격): 159탭, 5구역 도달, 보스 1회 성공, 작전 선택/실제 보유 1/1, 오류 0.
- 초기 캐주얼 패스에서 보스 뒤 연속 탭이 작전 카드를 오선택하는 문제를 발견했다. 450ms 입력 안정화만으로 부족해 카드 선택과 채택을 분리했고, 재검증에서 선택 카운터와 실제 보유가 일치했다.
- 그리디 밸런스 시뮬레이션은 보스를 기본 보상으로 건너뛰는 방치 경로에서도 첫 감사 2.9분, 11구역 5.3분, 오류 0으로 기존 허용 범위를 통과했다.
