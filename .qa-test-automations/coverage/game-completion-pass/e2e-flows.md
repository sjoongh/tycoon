# 게임 완성도 마감 패스 E2E 흐름

## Flow 1: 직원 팀 편성

1. 자원만 준비한 신규 런에서 직원 탭을 연다.
2. 접수·검수·운반·전산을 실제 채용 버튼으로 채용한다.
3. 첫 세 명 자동배치와 네 번째 대기, 필드 인원 3명을 확인한다.
4. 접수원을 실제 버튼으로 Lv.5까지 올리고 주무관 카드·월드 배지를 확인한다.
5. 접수원을 해제하고 전산관을 배치한 뒤 새로고침해 동일 슬롯을 확인한다.

## Flow 2: PWA 갱신

1. 프로덕션 미리보기에서 첫 서비스워커를 설치한다.
2. 새 바이트의 서비스워커를 배포해 `새 공문 도착`과 두 선택을 확인한다.
3. `지금 갱신`을 눌러 저장 시각 증가, waiting 해소, controller 교체를 확인한다.
4. 네트워크를 끊고 재로드해 게임 HUD가 다시 뜨는지 확인한다.

## Flow 3: 자연 플레이와 감사

1. 상태 주입 없이 오프닝부터 시작해 10분간 실제 화면을 탭한다.
2. 준비되는 시설 강화·직원 채용·사건 선택·보스 패턴·작전·피버를 실제 UI로 처리한다.
3. 첫 감사 도달 시간과 오류·교착 여부를 기록한다.
4. 결정적 3회 시뮬레이션으로 반복 감사 5~8분 범위를 교차 확인한다.
