# UI Readability E2E Flows

## Flow-UIR-1 — 시각 우선순위와 반응형

1. 신규 세이브 오프닝을 완료한다.
2. 3구역 완료 작전 회의를 열고 중앙 배너가 뒤에 남지 않는지 확인한다.
3. 작전을 선택한 뒤 구역 진입 배너가 재개되는지 확인한다.
4. 보상 중복과 위기 알림을 동시에 발생시켜 중앙 노출 최대 1개와 우선순위를 확인한다.
5. 구역·체제 진행률을 50%로 만들고 transform 값을 확인한다.
6. 390×844 및 360×740에서 글자 크기, 44px 설정 버튼, 가로 넘침을 확인한다.
7. reduced-motion에서 관련 transition이 0초인지 확인한다.

## Flow-UIR-2 — 신규 세이브 직접 플레이

1. GameState 주입 없이 오프닝부터 시작한다.
2. 90초간 탭·시설·직원·사건·작전·피니셔를 화면 조작으로 반복한다.
3. 작전 회의 주기, 피버와 재정비 횟수, 오류 배열을 확인한다.
4. 종료 스크린샷에서 중앙 중복 시스템 문구가 제거됐는지 눈으로 검토한다.
