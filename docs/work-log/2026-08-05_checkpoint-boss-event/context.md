## 근거와 입력

- 사용자 승인: `응 a로 승인하자`.
- 승인안: 3구역마다 8초 능동 체크포인트, 실패·건너뛰기 무페널티, 성공 시 완료 표 보상 +35%, 이후 작전 회의.
- 기존 90초 신규 세이브 플레이: 15구역 완료, 작전 5회, 피버 2회. 3구역 주기가 이미 빠르므로 긴 하드 보스는 부적합하다.
- 기존 코드: `GameState.advanceStage()`가 완료 구역 3·6·9…에서 작전 드래프트를 만들며 완료 보상은 다음 구역 진행도에 반영한다.
- 유사 게임 근거: Clicker Heroes식 시간제 보스는 체크포인트를 만들지만 실패 후 파밍 복귀가 반복 성장 벽이 될 수 있다.

## 제약

- 신규 통화·광고·과금·하드 실패 벽·전역 경제 재설계는 제외한다.
- 보스는 오프라인이나 백그라운드에서 자동 시작하지 않는다.
- 보스 UI와 작전 모달·피버 결산·중앙 알림을 동시에 표시하지 않는다.
- 사용자 소유 변경 `.omc/project-memory.json`, `.impeccable/`, `.omc/artifacts/`는 수정·커밋하지 않는다.
- E2E는 `localhost` 또는 `127.0.0.1`에서만 실행한다.

## 결정

- 8초 동안 현재 초당 생산과 직접 탭으로 보스 게이지를 채운다.
- 목표는 시작 시점의 비버프 초당 생산 8초분과 기본 탭 12회분으로 스냅샷한다.
- 성공 보너스는 구역 완료 기본 표 보상의 35%이며 새 구역 초기화 뒤 함께 지급한다.
- 실패·건너뛰기는 기본 보상을 그대로 받고 작전 회의로 이어진다.
- 보스 도전은 구역 완료 버튼을 누를 때만 시작한다.
