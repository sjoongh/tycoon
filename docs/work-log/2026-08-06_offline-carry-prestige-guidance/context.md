# Context — 오프라인 이월·감사 판단 개선

## 사용자 요청
- 남은 게임 개선을 순서대로 진행하면서 직접 플레이·리뷰·오류 검증한다.
- 3단계 A안: 오프라인 초과 진행 이월과 감사 타이밍 정보 개선.

## 관찰 증거
- 현재 `applyOfflineProgress()`는 `stage.progress`를 현재 목표에 clamp해 초과 진행을 버린다.
- 1시간 복귀: 보상 2,515표 중 구역 진행 초과 2,372표.
- 8시간 복귀: 구역 진행 초과 10,426표.
- 기본 8시간 한도, 효율 72%, 하루 1회 2배는 정상이다.
- 감사 배율은 장기 소프트캡이 작동하지만 UI가 상대 증가율을 설명하지 않는다.

## 제약
- 오프라인 표·해명 보상 및 누적 통계를 중복 지급하지 않는다.
- 보스·작전·감사 경제 공식은 유지한다.
- 구 세이브를 안전하게 정규화한다.
- 사용자 소유 `.omc/`, `.impeccable/` 변경은 작업 범위에서 제외한다.
