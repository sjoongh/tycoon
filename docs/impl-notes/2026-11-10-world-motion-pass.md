# 2026-11-10 — 월드 모션 패스 (새 아트 위에 "살아 있는" 느낌)

## 배경
- 아트 교체(PR #20) 뒤 남은 지적: 직원은 2프레임 3fps 교체, 국장은 4px 흔들림, 시설은 정지. 탭해도 화면 변화가 적다.

## 추가한 모션 (`src/world/WorldView.js`)
- 직원 작업 루프 `_startWorkLoop`: 제자리 squash·stretch(세로 0.962/가로 1.035, 400ms 왕복, 개체별 랜덤 위상) + 배지 미세 바운스. 프레임 교체는 5fps.
- 직원 심부름 `_courierRun`/`_walkWorker`: 6.5초마다 75% 확률로 접수창구 밖 직원 1명이 창구 앞 더미까지 총총 걸어가(바운스 125ms, 애니 1.8배속, 진행 방향으로 flip) 표 3장을 내려놓고 돌아온다. 걷는 동안 depth·배지·그림자 동기화. 제거·승급과 충돌하지 않게 `busy` 플래그.
- 시설 가동 모션 `_startPropIdle`: 분류기 ±1.6° 흔들림, 서버 미세 진동, 게시판 종이 펄럭(가로), 보관소·접수창구 느린 숨, 브리핑룸 맥동 + 3.8초마다 카메라 플래시(`_studioFlash`). 승급 펀치·`_pulseProp`는 idle을 멈췄다가 끝나면 재시작.
- 승급: 펀치에 4° 기울임 + 표 6장 분출 추가.
- 국장: 흔들림 위에 숨쉬기(세로 1.025, 1.4초) 추가, 탭 반동을 1.12/0.88 Back ease로 더 탄력 있게, 탭마다 표 2장 튐.
- 투표지 분출 풀: 목표 좌표를 스폰 기준 상대(±90, +30~120)로 바꿔 새 방 좌표계에 맞춤. 파티클 1.1배.
- 모든 추가 모션은 `motionReduced()`(설정 > 움직임 줄이기)면 생략.

## 슬롯 재배치 (`src/world/iso.js`)
