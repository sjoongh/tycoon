# 1.13.0 (versionCode 19) — 월간 시즌

레퍼런스 로드맵 장기 #1(`docs/research/reports/모바일 타이쿤 레퍼런스 고도화 방향.md`)이다. 무료 트랙만 있다. 실제 선거·정당·인물·로고·수치는 쓰지 않고, 모든 테마를 '가상 선거'로 부른다.

## 규칙 (`src/data/seasons.js`)
| 항목 | 규칙 |
|---|---|
| 테마 | 6종이 달마다 돈다(연×12+월 키 % 6). 2026년 11월은 '속보 경쟁 가상 선거', 12월은 '개표 축제 가상 선거'다 |
| 시즌 포인트 | 받는 순간에만 쌓인다. 일일 퀘스트 받기 +10, 주간 목표 받기 +60, 사건 체인 결말 +30, 특별 개표소 등급 동·은·금·정예 +15/25/40/60 |
| 무료 트랙 | 8단계. 단계별 필요 포인트와 보상은 아래 표와 같다 |
| 지급 | 단계에 도달하면 바로 지급한다. 받기 버튼이 없어 월말에 놓치는 보상이 없다 |
| 한정 모자 | 받으면 곧바로 장착된다. 꾸미기에서 바꿀 수 있다 |
| 시즌 발령 | rarity `season`, weight 0. 뽑기 풀과 전수집 업적(titlesOwned)에서 빠진다. 등급 순위가 가장 높아 대표 칭호가 된다. 6개월 뒤 같은 테마가 돌아오면 레벨업한다 |
| 월 전환 | 진행이 있던 지난 시즌만 기록에 남긴다(최대 6개). 이때 로그에 "N월 시즌 종료 · k/8단계"를 남기고 0부터 다시 시작한다 |
| 리셋 | 감사(prestige) 리셋 후에도 시즌 진행이 유지된다(`_metaKeptAcrossResets`) |

무료 트랙 단계별 보상:

| 단계 | 필요 포인트 | 보상 |
|---|---|---|
| 1 | 30 | 해명 80 |
| 2 | 80 | 인장 1 |
| 3 | 150 | 해명 150 |
| 4 | 240 | 이번 달 한정 모자 |
| 5 | 350 | 인장 2 |
| 6 | 480 | 해명 300 |
| 7 | 640 | 인장 3 |
| 8 | 820 | 이번 달 시즌 발령 |

- 포인트 수준은 대략 이렇게 잡았다.
  - 일일 퀘스트 5개를 매일 받으면 한 달 약 1,500P다.
  - 주간 목표만으로는 약 260P다.
  - 매일 들어오는 플레이어는 중순에 8단계를 마친다. 가끔 들어오는 플레이어도 모자(240P)까지는 닿는다.
- UI는 두 곳을 바꿨다.
  - 목표 탭 맨 위에 시즌 카드가 있다. 포인트 막대, 8단계 칩, D-day, 적립처를 보여 준다.
  - 꾸미기에서 시즌 모자는 보유했거나 이번 달 테마일 때만 칩으로 보인다.
  - 뽑기 카드의 보유 수와 확률은 뽑기 칭호 기준으로 바꿨다.

## 원화
- `scripts/art/jobs/season.json` → `aigen.py`(로컬 Quotio 프록시)로 생성했다. `cos-cap` 원화를 기준으로 편집해 6종을 만들었다: 헤드랜턴, 투표함 모자, 탐정 모자, 월계관, 기자 중절모, 고깔모자.
- `build_world_ai.py`는 모자별 배치를 정한다. 월계관은 세로로 0.42배 눌러 머리 위 원근에 맞췄다.
- 꾸미기 칩용 64px 단독 아이콘은 `public/art/world/cos-s-*-icon.webp`로 저장한다. 아이콘 아틀라스는 원본 팩이 없어 재생성하지 못하기 때문이다.
- `worldAtlas.js` 변경은 추가분뿐이다.
