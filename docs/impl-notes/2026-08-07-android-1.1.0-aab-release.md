# 2026-08-07 Android 1.1.0 AAB 릴리스

## 목표 / 확정 사항

- 이전 게임 완성도 마감 패스의 문서상 미완료 표시를 실제 운영 상태에 맞게 닫는다.
- Android 앱을 `versionName 1.1.0`, `versionCode 3`으로 올린다.
- 기존 로컬 release keystore로 서명된 AAB를 생성하고 검증한다.
- 변경을 커밋하고 PR로 병합한다. Play Console 업로드는 이번 범위에서 제외한다.

- 미승인 가정: Play Console 업로드와 스토어 출시 버튼 조작은 수행하지 않는다.

## 계획

1. 이전 완료 문서의 실제 상태와 Android 버전·서명 계약을 기준선으로 고정한다.
2. 문서의 운영 배포·머지 항목을 완료로 갱신하고 Android 버전을 `1.1.0 (3)`으로 올린다.
3. 웹 회귀 테스트와 빌드를 통과시킨 뒤 Capacitor Android 자산을 동기화한다.
4. release bundle을 생성하고 서명·패키지명·버전·해시를 검증한다.
5. 독립 리뷰와 PR CI를 통과한 뒤 squash merge한다.

## 판단 근거

- 기능 묶음이 게임 시스템·PWA·직원 전략을 포함하므로 patch보다 minor 릴리스 `1.1.0`이 의미상 맞다.
- Google Play의 업로드 식별자는 단조 증가해야 하므로 저장소의 `versionCode 2` 다음 값인 `3`을 사용한다.
- keystore와 비밀번호 파일은 기존 ignore 정책을 유지하며 커밋하지 않는다.

## 구현 결과

- `package.json`과 lockfile의 앱 표기 버전, Android `versionName`을 `1.1.0`으로 맞추고 `versionCode`를 `3`으로 올렸다.
- `npm run android:bundle` clean/no-daemon 스크립트와 README의 OpenJDK 21·로컬 서명·산출물 경로 안내를 추가했다.
- release 빌드는 properties 필수 항목과 keystore 실파일을 선검사하며, 누락 시 unsigned 산출물을 만들지 않고 즉시 실패한다.
- 이전 게임 완성도 마감 패스 문서의 PR #11, main CI, 운영 배포·smoke test 상태를 실제 완료 결과로 동기화했다.
- ignored 서명 자산은 격리 worktree에 임시 링크로만 연결했고 Git 변경 목록에 포함되지 않았다.

## ⚠️ DEVIATION (계획과 달라진 것 · 복병)

- ⚠️ 최초 release bundle 빌드를 OpenJDK 17로 실행했으나 Capacitor Android 8.5.0의 Java 소스 레벨 21 요구로 `invalid source release: 21`에서 중단됐다. → 기존 로컬 OpenJDK 21로 빌드 도구체인을 맞추고 전체 release bundle을 처음부터 다시 생성·검증한다. 앱 코드나 서명 설정 변경은 없다.
- ⚠️ 교차 검증에서 기존 release 설정이 properties 부재 시 unsigned bundle을 허용할 수 있고 npm 명령이 clean build를 강제하지 않는 점을 발견했다. → `preReleaseBuild` fail-closed 검사와 `--no-daemon clean bundleRelease`로 보강하고 서명 있음/없음 양쪽 경로를 재검증한다.
