# 앱 아이콘 · 스플래시 · 스토어 그래픽 교체

게임 아트가 손그림 카툰으로 바뀌었는데 아이콘은 옛 8비트 도트 국장 그대로였다. 런처·스플래시·PWA·Play 그래픽과 스토어 설명을 현재 아트에 맞췄다.

## 원화
- 국장 원화(`assets/art-src/ai-world/gov-3.png`)를 gpt-image 편집으로 아이콘용 상반신 포즈 3안으로 만들었다(`scripts/art/jobs/icon.json`, Quotio 로컬 프록시). 엄지척·투표함 안을 골라 `assets/art-src/icon/gov-icon-fg.png`로 두었다.
- 배경 햇살(주황 방사형 + 16갈래)은 코드로 그린다. 해상도가 바뀌어도 다시 생성할 필요가 없다.

## 생성
`python3 scripts/art/build_app_icon.py`(`npm run icons:generate`)가 한 번에 만든다.

| 대상 | 규칙 |
|---|---|
| Android 레거시 | `mipmap-*/ic_launcher.png`(둥근 사각), `ic_launcher_round.png`(원). ldpi~xxxhdpi 6밀도 |
| Android 적응형 | 108dp 전경·배경 레이어. 보이는 72dp 안에 얼굴이 들어가고, 몸통은 아래로 흘러 마스크에 잘린다. `mipmap-anydpi-v26`의 inset을 없앴다 |
| 스플래시 | API 24~30은 `drawable*/splash.png`(앱 배경 #14121c + 가운데 아이콘). API 31+는 `windowSplashScreenBackground` #14121c 위에 런처 아이콘 |
| PWA | `public/icons/icon-192·512.png`(둥근 사각), `icon-maskable-512.png`(안전 영역 80%). favicon도 같은 PNG |
| Play | `store/icon-512.png`(정사각, Play가 둥글린다), `store/feature-graphic.png` 1024×500 |

## 정리
- 옛 생성기(`scripts/_gen_icons.mjs`)와 도트 `public/icon.svg`를 지웠다. SW 사전 캐시·PWA 버전 해시 목록에서 빠졌고, 웹 알림 아이콘은 `/icons/icon-192.png`를 쓴다.
- 스토어 설명(`store/STORE_LISTING.md`)에서 '레트로 8비트 픽셀 아트'를 지우고 1.10~1.15 콘텐츠(헤드라인 스크랩·월간 시즌·기관 소집·지역 이주)를 반영했다.
- Play 반영 도구: `tools/play/upload-listing-images.mjs`(아이콘·그래픽), `tools/play/update-listing-text.mjs`(짧은·전체 설명). 둘 다 커밋 뒤 새 edit로 다시 읽어 대조한다.

## 검증
- 마스크 미리보기(원·둥근 사각·스쿼클)에서 얼굴이 잘리지 않는 것을 확인했다.
- 에뮬레이터(API 35) 디버그 빌드에서 앱 서랍 아이콘과 Android 12+ 스플래시를 스크린샷으로 확인했다.
- `npx vitest run` 272건, `npm run build` 통과.

## 아직 확인할 것
- 실기기·제조사 런처(삼성 One UI 등)의 아이콘 모양은 확인하지 않았다.
- API 30 이하 스플래시는 에뮬레이터로 확인하지 않았다.
