# 1.14.0 (versionCode 20) — 기관 소집 · 지역 이주

레퍼런스 로드맵 장기 #2·#3(`docs/research/reports/모바일 타이쿤 레퍼런스 고도화 방향.md`)이다. 규칙 상세는 `docs/impl-notes/2026-11-12-agency-and-moving.md`에 있다. 기관·인물·사건은 모두 가상이다.

## 규칙
| 항목 | 규칙 |
|---|---|
| 기관 소집 | 훈장으로 1회 소집한다. 특별검사팀 4, 언론 합동취재단 5, 국제 선거감시단 6 |
| 기관 사건 | 소집하면 일반 사건 자리의 30%가 기관 사건이다(기관당 4종). 효과는 특검 인장, 취재단 생산 ×3 생중계, 감시단 인증 8점당 훈장 1이다 |
| 기관 유지 | 감사(리셋) 후에도 소집·기록·인증 점수가 남는다 |
| 이주 연출 | 구역 승격 → 승격 카드 닫힘 → 암전(지역명·'N구역으로 이사') → 새 방에 이삿짐 상자 3개. 방 단계가 바뀌면 기존 확장 연출 끝에 상자가 떨어진다 |
| 이삿짐 상자 | 탭해서 하나씩 푼다. 표 = max(생산 15초분, 구역 완료 보상 8%)이고, 마지막 상자는 해명을 더 준다. 감사하면 사라진다 |
| 지난 지역 액자 | 오른쪽 벽 위쪽에 직전 구역부터 최대 4개 |

## 원화
- 새 원화는 없다. 상자는 잠긴 구획용 `world/lot-boxes`를 다시 쓰고, 액자는 도형과 기존 지역 아이콘(`region-N`)으로 그린다.
- 폰트 서브셋 2종(DoHyeon·Jua)을 새 문구 글자에 맞춰 다시 만들었다.
