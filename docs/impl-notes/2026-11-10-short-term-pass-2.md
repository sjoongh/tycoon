# 2026-11-10 — 레퍼런스 로드맵 단기 패스 2 (피드백 위계·주간 랭킹 뱃지·고지문·지역 현판/승격 카드)

근거: `docs/research/reports/모바일 타이쿤 레퍼런스 고도화 방향.md` 단기 5~8.

## 5. 피드백 위계
- 마일스톤(생산 ×2) 도달을 3단 위계의 최상위로: `GameState._emitMilestoneIfHit` → `milestone` 이벤트 → WorldView 시설 1.4배 펀치+기울임, 투표지 12장 분출, "★ Lv.N 생산 ×2!" 플로팅, 국장 환호. 탭(2장·플로팅) < 구매(펀치 1.22) < 마일스톤(1.4+분출+환호).
- 움직임 줄이기 설정이면 분출 생략. 파티클 상한(풀 40장) 유지.

## 6. 주간 랭킹 리셋 + 등급 뱃지 (`cloud.js`, `GameState`, `WorldView`, `DOMModalLayer`)
- 점수 문서에 `week`, `weekVotes`(이번 주 처리 표 = weeklyProgress) 추가. 이번 주 랭킹은 `updatedAt` 최근 100명 중 이번 주 기록만 `weekVotes`로 정렬(단일 필드 정렬, 복합 색인 불필요).
- 랭킹 모달에 탭 2개: "이번 주 개표 · N일 남음"(기본) / "도달 구역". 내 현재 순위와 예정 등급, 보유 뱃지 표시.
- 순위 기록: 세션 시작(클라우드 준비 후) 1회 + 랭킹 열 때. 5분마다 점수 제출.
- 주가 바뀌면 마지막 기록 순위로 등급 확정(`badgeTierFor`: 1~3 엘리트, ~10 골드, 상위 50%·최소 20위 실버, 나머지 브론즈) → `badges`(최근 8개) + 보상(엘리트 해명 300·인장 2, 골드 180·1, 실버 90, 브론즈 40) + 결과 모달.
- 벽 전시: 최근 4개 뱃지를 왼쪽 벽 액자(색 메달)로 그린다.
- 한계: 서버 집계가 아니라 클라이언트가 마지막으로 본 순위 기준. 주 막판에 접속하지 않으면 그 전 기록으로 확정된다. Firestore 규칙은 콘솔 관리라 새 필드는 기존 `scores/{uid}` 문서 안에 두었다.

## 7. 풍자 고지문
- 오프닝 카드와 설정 화면에 "창작 픽션" 고지가 이미 있음을 확인. 추가 변경 없음. 실명·로고·기호 번호 금지 원칙은 데이터 작성 규칙으로 유지(`docs/research` 보고서 참조).

## 8. 지역 현판 + 승격 1컷 카드
- 현판 윗줄 "믿어주세요" → 현재 지역명(`regionFor(area).name`), 승격 시 톡 튀며 교체.
- 구역 진입 배너를 "개표일보" 승격 카드로 교체: 시대·구역, 지역 아이콘, 승격 통지, 지역명, 한 줄 설명, 외신 헤드라인, "개표 시작" 버튼.
