# 2026-11-13 2차 — 메뉴 전체 화면 · 닫기 X · 문구 정리

사용자 지시(원문): "쓸모없는 문구들 보이는것도 정리해주고 메뉴 눌렀을때 x아이콘도 다 넣어주고 메뉴들 눌렀을때 그냥 화면에 다차는 구성으로 다 바꿔줘라"

## 해석(에이전트 판단 — 사용자 확인 전)
- "메뉴" = 하단 탭 5개와 설정·전국 지도·특별 개표소·랭킹.
- "화면에 다 차는" = 하단 탭은 상단 자원 줄·진행바 아래부터 탭 바까지(기존 full 상태). 자원 수치는 구매 판단에 필요해 남겼다. 설정·지도·특별 개표소·랭킹은 프레임 전체.
- 월드의 시설·직원을 직접 눌렀을 때는 기존처럼 일부만 펼친다(메뉴를 누른 경우가 아니고, 방금 누른 대상이 가려지지 않게). 이 경우에도 X는 있다.
- 보상 수령·확인 팝업, 도감 상세 카드는 메뉴가 아니라 그대로 카드형.

## 변경
| 항목 | 내용 |
|---|---|
| 하단 메뉴 | 탭·요약 줄을 누르면 항상 전체로 열림. 같은 탭을 다시 누르거나 X·아래로 끌기·뒤로 가기로 접힘. 탭별 반/전체 기억(`perTab`) 제거, 저장 상태 없으면 접힘에서 시작 |
| 닫기 X | 열린 시트 오른쪽 위(44px). 닫을 수 있는 팝업(`data-close`가 있는 `_openModal`)에도 오른쪽 위 X |
| 오버레이 | `.gp-map-ov` 계열(설정·지도·특별 개표소·랭킹) 여백·테두리 제거, 프레임 전체 |
| 지운 문구 | 출석 "매일 들러 개표국을 챙기세요", 지도 하단 안내·면책 중복, 설정 하단 게임명, 꾸미기 "진행하면 더 해금돼요 · 탭해서 장착/해제", 빈 슬롯 "직원을 배치하세요", 요약 줄 "보상을 받을 수 있습니다", 누적 랭킹 하단 "구역을 더 정복할수록 순위가 오릅니다" |
| 줄인 문구 | 뽑기 "아직 발령 없음", 닉네임 "최대 12자", 랭킹 빈 목록 "이번 주 기록 없음"/"기록 없음", 오프라인 "최대 N시간까지 적립" |
| 남긴 문구 | 규칙·제약·해금 조건(특별 개표소 종료 규칙, 주간 랭킹 보상, 훈장 해금, 시즌 포인트 출처, 작전 설명), 오프닝 3장, 튜토리얼 힌트, 면책(오프닝·설정) |

## 검증
- `scripts/_menusheettest.mjs`(신규) 통과: 탭 5개 전체로 열림·X로 닫힘, 같은 탭 토글, 월드 경로 일부 펼침, 뒤로 가기 접힘, 설정·지도·특별 개표소가 프레임을 꽉 채우고 X로 닫힘, 작전 현황 팝업 X.
- `_stagectatest` 통과, `npx vitest run` 296 통과, `npm run build` 통과. 390×844·1280×800 캡처 확인.

## 아직 확인할 것
- 위 해석 세 가지가 사용자 의도와 같은지(특히 자원 줄을 남긴 것, 월드 탭 시 일부 펼침 유지).
- 랭킹 화면은 로컬에서 닉네임 입력 단계까지만 확인(목록 화면 미확인). 실기기 미확인.

# 2026-11-13 4차 — 판단에 안 쓰이는 줄 제거

기준(사용자): 플레이 판단에 쓰이면 유지, 아니면 제거. 아래 분류는 에이전트 판단.

- 제거: 사건 탭 제목의 "· 처리 N건"과 "보상 xN.N" 줄, 감사 추천 카드의 적기·추천 설명 문장(라벨과 상승폭 수치는 유지), 목표 탭의 이미 달성한 업적 카드(달성 수는 "업적 · N/M").
- 유지: 감사 잠김 조건·"조금 더" 안내 문장, 사건 결말·도감·세트 진행 줄, 시설 유입/용량/적체, 개표소 확장 예고, 시즌 포인트 출처, 뽑기 확률, 남은 업적 진행률.
- 검증: vitest 296 통과, 빌드 통과, `_menusheettest` 통과, 사건·목표·감사 탭 캡처 확인.
