# 2026-11-13 UI/UX 정리 패스

요청: "전체적으로 ui/ux가 아직 부족" (구체 항목 지정 없음). 아래 항목은 로컬 캡처(390×844, 360×780, 1280×800, 1920×1080)를 직접 보고 고른 것이며, 사용자가 항목별로 확인한 목록은 아니다.

## 고친 것
| 문제(캡처로 확인) | 수정 |
|---|---|
| 390px에서 표 숫자가 잘림(`5459.6만` → 끝이 가려짐) | HUD 칩 줄의 오른쪽 여백 96→56px, 값 15px |
| 데스크톱·태블릿(폭 ≥430px): UI 레이어가 390×844 고정이라 높이 800에서는 탭 바가 잘리고 1080에서는 캔버스와 어긋남 | `main.js`가 프레임 높이로 `--ui-scale`을 계산, `.gp-ui`를 같은 배율로 scale. 시트 높이 계산은 `offset*`(CSS px) 기준으로 변경 |
| 알림 배너가 오른쪽 칩과 펼친 시트의 제목·랭킹 버튼을 가림 | 배너를 단계 칩 자리(HUD 바로 아래) 한 줄로 이동 |
| 목표 탭: float 랭킹 버튼 때문에 목록 전체가 오른쪽 80px을 비움 | 제목 줄을 flex로 |
| 구역 완료 버튼이 시설 탭 맨 아래에만 있어 접힌 시트에서는 안 보임 | HUD 단계 칩이 목표 달성 시 `N구역 완료 · 다음 구역으로`(보스 구역은 `최종 검증 시작`) 버튼이 됨. 동작은 기존 `advanceStage`와 같다 |
| 한글이 낱말 중간에서 줄바꿈(`밑바/닥`, `격리/합니다`) | `.gp-ui { word-break: keep-all }` |
| 월드 글자(레벨·개표 현황·간판)가 흐림 | GameScene에서 텍스트 해상도를 캔버스 배율에 맞춤. 라벨 9px·흰색 |
| 간판이 오른쪽 칩과 겹침, `전국 지도` 힌트가 안 읽힘 | 간판 폭 220→200, 힌트에 배경 |
| 출석 보상 아이콘이 회색 표 뭉치(`ui-calendar` 칸에 달력 그림이 없다) | `ui-gift` |
| 연쇄 사건 제목 표식 `↳`가 폰트에 없어 깨짐, 사각 픽셀 박스 | 둥근 `!` 표식 |
| 면책 문구 8px·저대비 | 9.5px, `#9aa7cb` |

## 검증
- `npx vitest run` 296 통과, `npm run build` 통과.
- `scripts/_stagectatest.mjs`(신규): 목표 미달 시 칩은 눌리지 않고, 달성 시 누르면 4→5구역. 보스 구역(3)에서는 보스전이 시작됨(수동 스크립트로 확인).
- 캡처: `scripts/_uxshots.mjs`(신규, `OUT`·`W`·`H`·`ONLY`·`EVAL`).
- `_uireadabilitytest`·`_bosschecktest`·`_a11ytest`는 main에서도 같은 지점에서 실패한다(접힌 시트 안의 `advanceStage` 버튼을 누르려 함 / 44px 터치 영역 기준). 이번 변경으로 생긴 실패가 아니며 고치지 않았다.
