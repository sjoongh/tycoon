# 헤드라인 스크랩 · 사건 결말 도감 · 공유 카드

레퍼런스 로드맵 장기 #6(`docs/research/reports/모바일 타이쿤 레퍼런스 고도화 방향.md`)이다. Cookie Clicker 뉴스 티커의 조건부 문구 모델과 수집 도감을 섞었다. 매체·인물·사건은 모두 가상이다.

## 규칙
| 항목 | 규칙 |
|---|---|
| 헤드라인 | 23종(`src/data/headlines.js`). 시각·날짜 7, 상태 4, 플레이 순간 12 |
| 판정 시점 | `clock` 헤드라인은 30틱(약 30초)마다 판정한다. 나머지는 해당 GameState 이벤트(combo·golden·boss-end·fever-start·cider·move-done·prestige-done·comm-collapse·special-tier·season-step·event-chain-ending)가 날 때 바로 판정한다 |
| 스크랩 | 조건을 처음 만족하면 첫 시각을 저장한다. 한 판정에 하나씩만 스크랩하고, 다시 뜨지 않는다. 감사(리셋) 후에도 남는다 |
| 보상 | 표·로그는 주지 않는다. 모은 수에 따라 영구 생산 보너스를 준다: 5장 +2%, 10장 +4%, 15장 +6%, 23장 전부 +10%. 사건 도감 보너스와 따로 곱한다 |
| 월드 연출 | 스크랩 순간 금색 '특종 스크랩 N/23 · 매체' 배너가 뜬다. 단계를 넘으면 '· 생산 +N%'를 붙인다. 여러 개면 3.8초 간격으로 차례로 띄우고, 그동안 일반 외신 배너는 쉰다 |
| 지도 도감 | 사건 도감 아래에 '헤드라인 스크랩 N/23'(현재 보너스·다음 단계)과 '사건 결말 N/9'(사건별 3결말)를 둔다. 못 본 칸은 조건 힌트만 보인다 |
| 공유 카드 | 스크랩한 헤드라인이나 발견한 결말을 누르면 상세가 열리고 '공유' 버튼이 있다. 1080×1350 신문 지면 이미지(`src/ui/shareCard.js`)를 만들어 Android는 공유 시트(@capacitor/filesystem 캐시 + @capacitor/share), 웹은 `navigator.share` 또는 다운로드로 내보낸다. 하단에 '창작 픽션 · 실존 기관·인물·단체와 무관'을 넣는다 |

## 함께 고친 것
- 화면 고정 연출(외신 배너·속보 배너·사이다 문구·골드 플래시)이 2배 줌 카메라에서 화면 밖에 그려지고, depth 200이라 시설 뒤에 깔리던 문제를 고쳤다.
  - 원인: `scrollFactor(0)` 객체도 뷰포트 중심 기준으로 줌된다.
  - 수정: `_screenPos(x, y)`로 `renderBase.baseScrollX/Y`만큼 보정한다. depth는 `OVERLAY_DEPTH`=2460(이주 암전 2450 위, HUD 2500 아래)으로 올렸다.

## 검증
- `npx vitest run` 272건 통과(헤드라인 신규 11건). `npm run build` 통과.
- Playwright(dev 서버, 시드 주입) 스크린샷으로 확인했다.
  - 지도 스크랩북·결말 섹션.
  - 헤드라인·결말 상세 카드.
  - 공유 캔버스 결과.
  - 웹 다운로드 대체 경로('이미지 저장됨').
  - 5번째 스크랩 시 금색 배너('특종 스크랩 5/23 · 만우절 통신 · 생산 +2%').

## 아직 확인할 것
- Android 실기기 공유 시트는 확인하지 않았다.
- 스크랩 빈도와 보너스 크기는 설계값이다. 체감은 미측정이다.
