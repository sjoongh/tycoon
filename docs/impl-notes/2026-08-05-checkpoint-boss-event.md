# 2026-08-05 체크포인트 보스 사건

## 목표 / 확정 사항
- 3·6·9구역처럼 3구역 단위 체크포인트에 8초 보스 대응을 추가한다.
- 보스 진행에는 현재 초당 생산과 직접 탭이 함께 기여하며, 피버·브리핑 같은 현재 버프도 자연스럽게 활용한다.
- 성공 시 해당 구역 완료 표 보상을 35% 추가 지급한다.
- 실패하거나 건너뛰어도 페널티 없이 기본 구역 보상을 받고 진행한다.
- 보스 연출을 닫은 뒤 구역을 완료하고 작전 회의를 열어 중앙 UI가 겹치지 않게 한다.

## Gate evidence
- 질문: `A — 체크포인트 감사관전`, `B — 하드 보스`, `C — 선택형 보스 사건`의 효과와 위험을 비교해 제시하고, A안의 8초 도전·무페널티 실패/건너뛰기·성공 보상 +35%·작전 회의 후속 규칙을 승인할지 확인했다.
- 사용자 답: `응 a로 승인하자`
- 승인된 범위: 3구역 체크포인트 보스 상태·규칙·저장 호환, 기존 픽셀 UI 안의 보스 진행 연출, 실패/건너뛰기/성공 보상, 작전 회의 순서, 관련 단위·E2E·실제 플레이 검증.
- 미승인 가정: 신규 통화, 과금·광고, 하드 실패 벽, 전역 경제 재설계, 별도 대형 아트 제작은 구현하지 않는다.

## 계획
1. 보스 정의와 3구역 체크포인트 규칙을 데이터 모듈로 분리한다.
2. GameState에 저장 정규화, 시작·진행·성공·건너뛰기·만료 복구를 구현한다.
3. 기존 구역 완료 버튼과 중앙 연출 큐 사이에 비차단 보스 HUD를 연결한다.
4. 상태 경계·저장·프레스티지·작전 순서 단위 테스트와 모바일/데스크톱 E2E를 추가한다.
5. 신규 세이브로 직접 플레이하고 보스 빈도·난이도·오류를 조정한다.

## 판단 근거
- 기존 신규 세이브 90초 고강도 플레이는 15구역을 완료해 3구역 주기가 5회 발생했다. 30초 하드 보스는 플레이 대부분을 점유하므로 8초 마이크로 챌린지로 제한한다.
- 기존 3구역 완료 직후 작전 회의가 열리므로 보스는 완료 직전의 능동 플레이, 작전은 완료 직후의 전략 보상으로 역할을 분리한다.
- Clicker Heroes의 시간제 보스는 명확한 체크포인트를 제공하지만 실패 시 파밍 복귀가 반복 성장 벽으로 평가된다. 이 게임은 실패를 보상 차이로만 처리해 방치 흐름을 보존한다.
- 자동 시작은 백그라운드·복귀 사용자에게 억울한 실패를 만들 수 있으므로 사용자의 완료 버튼 입력으로만 시작한다.
