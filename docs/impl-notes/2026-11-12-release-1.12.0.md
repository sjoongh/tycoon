# 1.12.0 (versionCode 18) — 잠긴 구획 미리보기 + 확장 연출

레퍼런스 로드맵 중기 #1 후속(`docs/research/reports/모바일 타이쿤 레퍼런스 고도화 방향.md`).
- 잠긴 구획: 테이프+박스+'증설 예정' 입간판.
- 확장 연출: 테이프 끊김 → 타일 행 단위 60ms 스태거 → 줌 0.92 → 소품 자동 배치 → 직원 1명 진입.
- 경제에는 영향이 없다.

## 규칙 (`src/world/lockedLot.js`)
| 항목 | 규칙 |
|---|---|
| 부지 표시 | 다음 방 단계가 있으면(1~9구역) 오른벽 뒤에 그린다. 11×11(10구역~)은 부지가 없다 |
| 입간판 | "증설 예정" + 다음 단계 개방 구역(3·6·10구역) |
| 탭 | 입간판·박스를 탭하면 "개표소 9×9 확장 · 6구역부터"를 띄운다. 득표 탭도 그대로 센다(passTap) |
| 부지 크기 | 오른쪽 위 HUD 칩(오늘의 접수·생산 2배, x≥304) 왼쪽에 들어오게 가장 먼 차단봉 x ≤ 292로 맞춘다 |

- 잠긴 구획과 사용 가능한 방의 대비:
  - 부지는 어두운 회색 바닥, 흰 점선 타일, 차단봉, 노랑·검정 공사 테이프로 그린다.
  - 테이프는 벽 쪽 한 변이 열려 있다. 왼쪽·뒤쪽 변은 소품 뒤로, 오른쪽 변은 앞으로 그린다.
- 확장 연출(`WorldView._playExpansion`):
  1. 승격 카드 같은 모달이 떠 있으면 닫힌 뒤에 시작한다(최대 90초 대기).
  2. 옛 부지의 테이프가 가운데서 끊겨 늘어지고 소품이 사라진다.
  3. 새 방 이미지를 위에서부터 `setCrop`으로 드러낸다. 한 단계는 i+j 두 줄이며 60ms 간격이고, 공개되는 타일이 반짝인다.
     - 커스텀 Phaser 빌드에 마스크가 없어서 crop을 썼다.
  4. 카메라를 0.92로 줌 아웃했다가 되돌린다. 사용자가 핀치 줌 중이면 생략한다.
  5. 시설이 80ms 간격으로 떨어져 자리 잡는다. 이어서 라벨·국장·현수막·배지가 나타난다.
  6. 직원 한 명이 문에서 자리로 걸어 들어온다. 나머지 직원은 제자리에 나타난다.
  7. 새 부지를 다음 단계 기준으로 다시 세운다.
- 연출 중에는 반입 차량·방문객·상주 NPC를 새로 만들지 않는다.
- 모션 줄이기 설정에서는 연출 없이 즉시 전환하고 안내 문구만 띄운다.
- 연출 도중 단계가 다시 바뀌거나 화면이 파괴되면 `_cancelExpansion`이 타이머를 끊고 알파·crop을 복구한다.

## 원화
- `scripts/art/jobs/locked-lot.json` → `aigen.py`(로컬 Quotio 프록시)로 생성했다. 박스 더미, 입간판, 차단봉 3종이며 박스를 참조 이미지로 써서 화풍을 맞췄다.
- `build_world_ai.py`에 lot 섹션을 추가했다. 입간판의 크림색 패널 영역을 행·열 다수결로 검출해 `worldAtlas.js`의 `lot.sign.panel`에 기록하고, 글자를 그 위에 얹는다.
- 입간판 글자는 카메라 2배 줌에서 흐려지지 않게 2배 크기로 그린 뒤 절반으로 줄였다.
