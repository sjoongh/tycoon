## 인장 공식 (`GameState.prestigePreview`)
- 이전: `max(4, (구역−3)×4 + 시설합/12 + 사건/3)` — 생애·런 수입과 무관해 "더 키우면 더 받는다"가 없었다.
- 변경: `max(4, (구역−3)×4 + 시설합/24 + 사건/3 + floor(2×√(이번 런 처리 표 / 44,000)))` × 기존 감사 강화 배율. 수입이 늘수록 인장이 √로 계속 늘어난다(AdVenture Capitalist 엔젤 `150×√(수입/1e15)`, Cookie Clicker ∛ 모델).
- 감사 탭: "지금 감사 +N 인장 · 1시간 더 키우면 +M"(`prestigeProjection().earnedIn1h` = 초당 생산×3600을 더한 미리보기). 지금 할지 더 키울지 판단을 돕는다.
- 밸런스 시뮬(3탭/초): 첫 감사 611s(인장 11→14), 반복 405/350s — 목표 480~720 / 300~480 안.

## 병목 기회형 전환
- 믿음 하락 유예: 적체가 1분치 용량을 넘기 전까지는 믿음을 깎지 않는다(그 초과분만 기존 비율). Egg Inc 이중 리미터처럼 '고민거리'로 두고 즉시 벌칙은 없앤다.
- 적체 해소 보너스: 20초치 용량 이상 쌓였던 적체를 0까지 소화하면 최대 적체의 30%를 보너스 표로 + "적체 해소!" 플로팅·국장 환호. 병목을 푸는 행동이 이득이 된다.
- 가독성: 병목일 때 시설 선택 칩에서 용량 시설(capacity ≥ 1.0: 분류·전산·기록)에 빨간 링과 "용량" 꼬리표(Idle Supermarket의 빨간 개선 표시). 기존 용량 줄 "병목 · 분류·기록 증설"과 함께.
- 오프라인은 원래 적체·믿음 벌칙 없음(유지).
