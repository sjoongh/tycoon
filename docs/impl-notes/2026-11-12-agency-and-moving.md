# 기관 소집 · 지역 이주 연출

레퍼런스 로드맵 장기 #2·#3(`docs/research/reports/모바일 타이쿤 레퍼런스 고도화 방향.md`)이다. 기관·인물·사건은 모두 가상이다.

## #2 기관 소집 — 훈장이 새 사건군을 연다 (`src/data/agencies.js`)
| 항목 | 규칙 |
|---|---|
| 소집 | 훈장 상점 '기관 소집 · 새 사건' 칸에서 1회 구매한다. 특별검사팀 훈장 4, 언론 합동취재단 5, 국제 선거감시단 6 |
| 출현 | 소집한 기관이 있으면 일반 사건 자리의 30%가 기관 사건이다. 아직 못 본 사건은 가중치 ×2.5 |
| 특검 | 해결하면 제도인장을 바로 준다(1~2개). 생산 배율용 누적 인장(totalSeals)은 늘리지 않는다 |
| 취재단 | 생중계 30~60초 동안 생산 ×3이다. 더 센 버프(속보 ×7 등)가 켜져 있으면 배율은 두고 같은 추가 생산만큼 시간만 늘린다 |
| 감시단 | 인증 점수 1~2점을 준다. 8점마다 훈장 1개(medals·totalMedals 모두) |
| 기록 | 기관 사건은 사건 도감과 따로 센다(기관별 해결 수·본 사건). 감사(리셋)와 재로드 후에도 소집·기록·인증 점수가 남는다 |

- 기관마다 사건이 4종이고, 모든 선택지에 그 기관 효과가 있다.
- UI는 세 곳이다.
  - 훈장 상점의 기관 칸: 비용, 효과, 해결 수, 감시단 인증 막대.
  - 사건 카드: 기관 색 배지, 효과 칩.
  - 사건 탭 대기 패널: 소집한 기관 줄.

## #3 지역 이주 — 이삿짐 상자와 지난 지역 액자 (`src/data/moving.js`)
| 항목 | 규칙 |
|---|---|
| 승격 연출 | 구역을 넘으면 승격 카드가 닫힌 뒤 암전된다. 지역명과 'N구역으로 이사'가 뜨고 상자가 화면을 가로지른다(약 1.6초). 방 단계가 바뀌는 승격은 기존 확장 연출을 쓰고, 그 끝에 상자를 떨어뜨린다 |
| 이삿짐 상자 | 새 구역은 상자 3개로 시작한다. 앞쪽 왼편 바닥에 쌓이고 가끔 흔들린다. 탭하면 하나씩 풀린다 |
| 상자 보상 | 표 = max(현재 생산 15초분, 구역 완료 보상의 8%). 마지막 상자는 해명(구역 완료 해명의 절반)을 더 주고 로그에 'N구역 이삿짐 정리 완료'를 남긴다 |
| 나오는 물건 | 옛 명패 → 투표함 열쇠 꾸러미 → 지난 구역 단체 사진 |
| 지난 지역 액자 | 오른쪽 벽 위쪽에 직전 구역부터 최대 4개를 지역 아이콘으로 건다. 탭하면 'N구역 · 지역명'이 뜬다 |
| 감사와 분리 | 상자 수는 구역 진행(stage)에 있다. 감사하면 사라지고, 재로드 후에는 남은 개수 그대로다 |

- 상자는 수집 대상이라 탭해도 득표 탭으로 넘기지 않는다. 액자는 시설처럼 득표 탭도 함께 센다.
- 모션 줄이기 설정에서는 암전·낙하·흔들림 없이 상자만 바로 놓인다.

## 검증
- `npx vitest run` 260건 통과.
  - 신규 `src/state/GameState.agency.test.js` 12건: 데이터 구성, 저장 값 정리, 소집 전후 출현, 기관별 효과(인장·생중계 연장·인증→훈장), 도감 분리, 감사·재로드 유지.
  - 신규 `src/state/GameState.moving.test.js` 6건: 승격 시 상자 3개, 순서대로 보상·마지막 해명·로그, 보상 공식, 저장 값 정리·재로드 유지, 감사 시 소멸, 액자 구역 목록.
  - `npm run build` 통과.
- Playwright 스크린샷(dev 서버, 시드 주입)으로 확인한 것:
  - 훈장 상점 기관 칸, 기관 사건 카드, 사건 탭 패널.
  - 2·4·7·11구역(방 4단계 전부)의 상자 위치와 액자. 상자가 긴급 브리핑 버튼에 가리지 않는다.
  - 4→5구역 승격 중간 프레임(암전, 지역명, 상자 이동), 승격 직후 상자 탭(남은 상자 2개).
  - 확인 중에 고친 것 두 가지.
    - 액자 4번째가 게시판 위에 가려져 간격과 크기를 줄였다.
    - 암전 레이어가 시설·직원보다 아래에 깔려 depth를 2450(HUD 아래)으로 올렸다.

## 아직 확인할 것
- 실기기에서 승격 카드 → 암전 순서와 상자 탭 감도는 확인하지 않았다.
- 기관 사건 30% 비율과 상자 보상 크기는 설계값이다. 실제 체감·사용률은 미측정이다.
