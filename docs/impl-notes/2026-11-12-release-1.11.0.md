# 1.11.0 (versionCode 17) — 앰비언트 3종

레퍼런스 로드맵 #10(`docs/research/reports/모바일 타이쿤 레퍼런스 고도화 방향.md`). 경제에는 영향이 없다. 개표소가 커질수록 화면이 더 붐비게 보이게 하는 연출이다.

## 규칙 (`src/world/ambient.js`)
| 항목 | 규칙 |
|---|---|
| 투표함 반입 차량 | 시간당 득표(초당×3600)로 단계를 정한다. 리어카 → 1톤 트럭(50만/h) → 호송차(1000만/h) |
| 방문객 동시 상한 | 방 단계별 4/5/6/6명. 빈 대기 자리 중 창구에 가까운 칸부터 채운다 |
| 상주 NPC | 분류기·보관함·브리핑이 Lv.12(시설 티어 3) 이상이면 옆에 참관인·경찰·기자가 상주한다. 직원 3명 상한과는 별개다 |

- 차량 임계는 `scripts/_balancesim.mjs` 결과로 정했다.
  - 1회차 종료 시점 시간당 약 190만~250만 → 트럭.
  - 깊은 회차(11구역) 시간당 약 2900만 → 호송차.
- 차량은 방 왼벽 뒤 도로로 들어온다.
  - 첫 도착은 9~15초 뒤, 이후 40~60초 간격이다.
  - 문보다 0.9타일 아래에 멈춘다. 벽 위 구역 배지와 겹치지 않게 하기 위해서다.
  - 1+단계 수만큼 투표지를 문 앞으로 하역한 뒤 빠져나간다.
- 단계가 오른 뒤 첫 도착 때 "반입 차량 교체 · 이름"을 띄운다.
- 차량을 탭하면 현재 시간당 득표와 다음 단계 임계를 보여 준다.
- 상주 NPC를 탭하면 대사가 나온다. 기자는 가끔 카메라 플래시를 터뜨린다.
  - 같은 방 단계 안에서 새로 상주하면 "○○ 상주 시작"을 띄운다.
  - 5×5 방에는 분류기 자리만 있다.
- 모션 줄이기 설정에서는 차량과 상주 NPC 움직임을 생략한다.
