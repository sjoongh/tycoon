# 2026-11-11 — 실기기(에뮬레이터) QA와 수정

환경: Android 에뮬레이터 `gaepyo_qa_api35`(API 35, arm64, 1080×2340), 디버그 APK(현재 main과 같은 구성), `adb input`으로 실제 터치·스와이프·뒤로가기 입력.

## 발견 → 수정
1. **Android 뒤로가기가 아무 동작도 하지 않음(기존 버그).** 지도·설정 오버레이(`.gp-map-ov`)가 숨긴 채 항상 DOM에 있어서, 뒤로가기 처리기가 매번 그 숨은 창을 "닫고" 끝났다. 시트 접기도, 앱 최소화도 안 됐다. → 보이는 오버레이만 대상으로(`!hidden && getClientRects().length`). 수정 후 전체→반→접힘→앱 최소화 순서 확인.
2. **튜토리얼 손가락이 가리키는 접수창구를 누르면 표가 처리되지 않음.** 시설 탭이 득표 탭을 막고 시트를 열었다. → 시설·직원·유권자에 `passTap`을 달아 각자 반응하면서 득표 탭도 그대로 센다. 시설 탭은 선택만 바꾸고 시트를 자동으로 펼치지 않는다(이름 플로팅은 선택이 바뀔 때만). 황금 투표함·아이템·표 뭉치는 계속 득표 탭과 분리. 수정 후 접수창구 위 10회 탭 → 표 +37 확인.
3. **첫 플레이에서 시트가 반펼침이라 "화면을 탭하세요" 안내가 시트에 겹침.** → 온보딩 전 새 유저는 접힘으로 시작, 안내 위치를 시트 높이 기준(`--panel-h`)으로, 전체 시트에서는 숨김.
4. **시작 직후 "적체 2표 · 믿음 -0.1/분" 경고.** 1분 유예를 넣었는데 경고는 적체 1표부터 떴다. → 실제로 믿음이 깎일 때(유예 초과)만 표시.
5. **오프닝 카드가 예전 도트 초상화.** → 새 카툰 아트(국장 1단계, 분류함·게시판 3티어)로 교체, 도트 import 제거.
6. **숨긴 요소가 빈 막대·빈 알약으로 보임(오른쪽 HUD 칩 3개, 믿음 상태 배지).** `display:flex/block` 규칙이 `hidden` 속성을 덮었다. → `.gp-ui [hidden] { display: none !important; }`.

## 확인한 것(문제 없음)
- 실제 터치로 탭·핀치 없는 스와이프 시트 드래그(핸들/요약 줄) 정상, 텍스처 전부 로드(로그상 아트 요청 성공).

## 남은 관찰
- 상태바를 겹치지 않는 설정(`overlaysWebView:false`)이라 실제 표시 영역 비율이 390×844보다 넓어 좌우에 약 20px 여백(FIT). 기존 설계 그대로.
- 프레임률 수치는 에뮬레이터 소프트웨어 렌더라 실측 의미가 없어 기록하지 않음.
