# 1.15.0 (versionCode 21) — 헤드라인 스크랩 · 사건 결말 도감

레퍼런스 로드맵 장기 #6(`docs/research/reports/모바일 타이쿤 레퍼런스 고도화 방향.md`)이다. 규칙 상세는 `docs/impl-notes/2026-11-12-headline-codex.md`에 있다. 매체·인물·사건은 모두 가상이다.
