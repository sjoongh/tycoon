# Free Non-Pixel (Cartoon / Soft-3D) Art Sources — 개표국 Idle Tycoon

Date: 2026-10-21. Target look: Idle Miner Tycoon / Idle Office Tycoon / AdVenture Capitalist — smooth vector cartoon or soft-3D renders, glossy rounded icons, chunky rounded gradient buttons and panels. Portrait phone. **Pixel art explicitly rejected.**

Companion doc: `2026-10-21-free-asset-sources.md` is the earlier *pixel* inventory; everything pixel there is now out of scope. The game-icons.net concept→icon mapping in that doc (section 1d) is still valid and reused here.

Verification: licenses were read from each asset's own page unless marked **(secondary)**. Pages that blocked automated fetch (403): Flaticon, Icons8, Freepik/Magnific license docs, Leonardo and Ideogram pricing, naver hangeul — those rows cite official help-center/ToS text surfaced by search and are flagged. Nothing was downloaded except the Jalnan license PDF (read for its text).
